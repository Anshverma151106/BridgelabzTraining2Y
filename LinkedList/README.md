# Linked List Assignment – Beginner-Friendly Java Solutions

These are simplified, classroom-level solutions for a B.Tech 2nd-year student.
They use basic Java concepts: classes, objects, Scanner, if-else, loops, and linked-list nodes.

## Solutions
1. Student Record Management – Singly Linked List
2. Movie Management – Doubly Linked List
3. Task Scheduler – Circular Linked List
4. Inventory Management – Singly Linked List
5. Library Management – Doubly Linked List
6. Round Robin Scheduling – Circular Linked List
7. Social Media Friends – Singly Linked List
8. Text Editor Undo/Redo – Doubly Linked List
9. Ticket Reservation – Circular Linked List

## Run any one program
Open terminal inside its folder and run:

    javac Main.java
    java Main

Each folder has a separate `Main.java`. Run one solution at a time.

## Notes
- The code is intentionally kept straightforward for learning and viva preparation.
- Positions are counted from 1.
- In the task scheduler and ticket system, circular traversal stops when it reaches the head again.
- The text editor stores up to 10 text states.
- For round-robin scheduling, priority is stored as required in the question; standard Round Robin uses the time quantum, not priority.
